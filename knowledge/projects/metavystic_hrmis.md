# Metavystic HRMIS

## Overview
A comprehensive end-to-end human resource management platform built at Metavystic that digitises and automates the full employee lifecycle: recruitment, onboarding, workforce administration, attendance tracking, performance management, asset allocation and offboarding.

## Design
Built around centralised data, configurable workflows, role-based access control and real-time reporting.

## Technologies
Django, JavaScript, role-based access, workflows, reporting.
